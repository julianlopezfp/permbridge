The Additional Use Grant is `None`. BSL permits copying, modification,

evaluation, and testing. Production use of a BSL-covered version before its
Change Date requires a separate commercial agreement with the Licensor. The

source-available, not OSI Open Source before the Change Date.

## Change Date for each version

Each Git commit that contains this BSL license identifies a specific version
of the Licensed Work. Its Change Date is four calendar years after that
commit's UTC committer timestamp. A tagged release or source archive inherits
the Change Date of the commit it identifies. Inspect the timestamp with
`git show -s --format=%cI <commit>`; convert the result to UTC, then apply the
same time and calendar month/day four years later. If the starting date is
February 29 and the fourth year lacks that date, use February 28. No later edit
to `LICENSE` resets the Change Date of an already distributed commit.

BSL 1.1 also makes the Change License effective on the fourth anniversary of
the first publicly available distribution of that specific version under BSL,
if that occurs earlier. This license cap controls even if a commit timestamp is
unusual. Record first-publication dates in GitHub release notes
when publishing tagged releases; for an untagged commit, the relevant event is
its first public availability on the repository. The exact controlling date is
the earlier of the parameter date and that four-year public-distribution cap.

On that date, the version becomes available under **Apache License 2.0** as
the Change License. Apache 2.0 is compatible with GPLv3, which satisfies
BSL 1.1's requirement of compatibility with GPL version 2 or a later version.
The change applies separately to each version; newer commits do not extend an
older version's BSL period.

## Earlier versions and participation

Versions published before this licensing change were offered under MIT. Their
existing MIT grants are not withdrawn. The BSL terms apply to the new BSL
versions; users may continue to obtain earlier versions from Git history under
their original terms. The [NOTICE](../NOTICE) identifies the author without
adding headers to every source file.
